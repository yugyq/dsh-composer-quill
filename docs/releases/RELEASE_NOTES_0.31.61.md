# 0.31.61

这一版没有来自新报告的功能，是三组实测逼出来的三处修正。

## 连续忽略三条后，暂停整段改写

拿日志里的真实分布算：主路径建议（草稿 6/20 字、强度「最高」）30 条里 47% 超过 2.5 秒。同一批里 `queueMs` 的 p50 只有 **4 ms**——去抖和历史往返几乎不占时间，等待全在模型。所以「加个看门狗」等于用产量换体感：2.5 秒预算会砍掉近一半建议。

真正没被花掉的成本是**反复被忽略的整段改写**：它最慢、最长，也最容易被直接按 Esc。现在连续忽略三条后只保留「在句尾接着写」，整段改写暂停；采纳任意一条即恢复，切会话清零。设置里有开关（默认开）。

## 1–3 字的草稿不再付思考成本

短草稿走短分支，而它此前会继承面板上的强度。同一条 1 字草稿直连对照：

| 强度 | 总耗时 | 思考 | 能不能用 |
| --- | --- | --- | --- |
| 显式 `none` | 435–925 ms | 0 字 | 6/6 |
| `xhigh` | 2975–7192 ms | 1710–4644 字 | 3 次里 1 次接不上 |
| 不传参数 | 2266–2796 ms | 吃满 384 额度 | 正文 0 字、`finish: length` |

最后一行就是生产里「空回复」的形状。现在短分支强制 `off`：修复后 60 次真实调用里短草稿 p50 **833 ms**，而此前四条真实的 1–3 字草稿是 1888 / 1919 / 2245 / 5257 ms。

**4 字以上没有跟着强制。** 24 条对照里 `off` 出了 5 处病句或语气漂移（「还需要确认下 preflight 的输出。」），`xhigh` 出 2 处——边界只留在 1–3 字，其余仍按面板。

## 日志不再把「已送达」记成静默

- `first-delta` 拆成 `queueMs` 与 `modelMs`：60 条实测 `queueMs` p50 **4 ms**、`modelMs` p50 **1216 ms**。
- `stream-end` 增加 `path` `model` `effort` `chars` `reasoning` `finish` `delivered`；没有 `path` 时，短分支（不发 delta、只发一帧 `final`）会被算进主路径的延迟。
- 短分支只发 `final`，而终态只看 delta，于是 28 条浏览器明明收到了的建议全被记成 `silent`。现在 `final` 也算送达。
- 模型调用会故意活过被取消的请求，它晚到的首字原本落进日志却没有终态，被读成「这条请求 2.2 秒没出字」。现在带 `late: true`，另记 `stream-late`。
