0.32.0 收的是同一类问题：**同一件事有两个来源**。同一份草稿因为走 SSE 还是走 JSON，会拿到两个问题、两份预算、两次计费；状态文件会因为环境变量到得早晚分家；3.5k 行浏览器代码只有一个文件。这一版把它们逐个收口。

先说三条你能看见的变化。

## 三条行为变化

| 场景 | 之前 | 现在 |
|---|---|---|
| 长草稿（≥240 字）走 JSON 兜底路 | 改写预算 384 token，一段改写可能被截断 | 768 token，与 SSE 路一致 |
| 1–3 字草稿走 JSON 兜底路 | 跟着面板的思考强度，一两个字的草稿也可能先想几秒 | 强制关思考，与 SSE 路一致 |
| 状态文件的位置 | Host 环境变量晚到时会落到裸 home 目录，日志和账本分家 | 只认 `DSH_PROFILE_DIR` → `DSH_HOME` → `~/.dsh`，首次运行会把目录建出来 |

第一、二条只在 SSE 不可用时（旧客户端、非流式请求）才会遇到，但遇到时是实打实的截断与几秒空等。第三条是账本被清零那次的同类问题：`cacheFile()` 里那行 `DSH_PROFILE_DIR ?? DSH_HOME ?? homedir()` 是死代码，真正的规则在 `stateDirectory()`，它原来会回退到裸 home。

## 两条草稿不再各问各的

`composePlan(draft)` 现在拥有两条传输都必须同意的一切：用哪套提示词、输出预算、转录窗口、最短合法尾巴。`sentencePrompt()` 也合回一个——JSON 侧原来问得更短，还漏掉风格画像与会话摘要。

顺带：同一缓存键的补写，无论哪条传输先到，只付一次调用；后来的等它写完再读缓存（`composeStream()` 默认 `epoch: 0`，两边才拼得出同一个键）。实测 5 次取消里有 2 次模型照样跑完、产物没人能复用，这类白花的调用现在也会在最后一个等待者离开时被掐掉。

## 尾巴不再把草稿的最后一个词说一遍

48 次真实调用里有 5 条尾巴以草稿末尾的词开头（`…三个字段需要` → `需要跟后端确认`），插进去读成「需要需要跟后端确认」。现在解析回复前先剪掉 2–8 字的回声；1 字通常是真续写（「降到」+「到最低」），不剪。

## 剩下的都是内部的

- **能力探测只付一次**：宿主不提供 reasoning 元数据，所以「这家模型拒绝 `reasoningEffort`」原来每条建议都撞一次（发带 effort 的请求 → 拿到终结错误 → 去掉重发）。现在按 `provider/model` 记住，进程内只探一次。
- **浏览器端拆成八个源文件**：`client/` 下 prelude、store、config、geometry、ghost-layer、hooks、dock、entry，由零依赖的 `dev/tools/build-client.mjs` 拼成仍然自足的 `client.js`。`npm test` 会检查产物与源同步，改源忘重建会红。没有走包内 chunk：那是构建器生成的协议，手写插件押上去就是「假设宿主实现细节」。
- **宿主漂移不再拖垮输入框**：`client/entry.js` 在 `slots`/`locale` 缺失时报 `apply-unsupported`，而不是激活时抛异常。
- **隐私措辞改成事实**：README 原来写「全部留在本机」，实际最近两轮、风格摘要和草稿都会发给所配置的模型服务。现在中英 README、SECURITY、ARCHITECTURE 都这么写，并说明打码只覆盖九种凭证形状、建议缓存是明文。

## 验证

- `npm test` — **158 passed**（156 条来自这次重构，2 条是回声修剪）
- `npm run check:client` — 产物与 `client/` 一致
- 浏览器场景 `dev/verify/verify_daily.py` — **66/66 passed**（含 S50 两次忽略阈值、S51/S51b 等待期不画未验证内容、S54/S54b Tab 口径）
- CI：`unit (node 20)`、`unit (node 22)`、`browser scenarios` 三 job 全绿

## 兼容与升级

- 五个路由、设置项、缓存键格式、配置结构都没变；`engines` 不变。
- 状态文件沿用 profile 目录里的原文件。旧版本落在裸 home 的日志/缓存不再读取（都是诊断与缓存，可以直接删）；用量账本仍会从旧位置合并，只读。
- 包体多带 `client/` 八个源文件与构建器，约 160KB；运行时不需要它们。
- Python 场景脚本现在 3.10 也能跑（原来有一处 f-string 只认 3.12）。

```bash
dsh plugin update dsh-composer-quill
```

`index.js` 变了，升级后需要**重启桌面应用**（`Ctrl+R` 只重载浏览器端）。
